## Stock Market Performance Analysis - Data Engineering Project ##

This project showcases an end-to-end cloud-native data pipeline built using AWS and Snowflake to analyze historical stock market performance.

## Tools & Services Used: ##

AWS EC2 – Hosted pipeline scripts and controlled workflow execution..

AWS S3 – Stored raw stock market data from external APIs.

AWS Lambda – Triggered data ingestion and transformation tasks.

AWS Glue – Performed ETL operations on the ingested data.

Snowflake – Data warehousing and SQL-based analysis.

Snowflake Dashboard – Visualized key stock trends and performance metrics.

## What the Project Does: ##

Connects to a public financial API yahaoo finance to retrieve stock prices, Stores raw and transformed data in a scalable cloud storage S3, and enables quick business insights via interactive dashboards.

## Key Highlights: ##

Demonstrates practical understanding of modern data engineering workflows.

Integrates multiple AWS services and Snowflake into one seamless pipeline.

Solves a real-world problem with data-driven insights.
